02 · How it is built

Eight agents, one frozen interface, no shared guesses.

Every box below is one file with exactly one owner. Nobody reads anybody else’s source: each lane codes against the signature written in CONTRACT.md and nothing else. That is what lets the whole system be built in parallel in a single day — and it is why the contract, the config and the type definitions are frozen underneath everything.
