rulial-markets · docs/diagrams

Four diagrams: what, how, why, and how honest.

Each one is a single self-contained HTML file with inline SVG, sized for a projector and aware of light and dark. Read them in order. The third is the one that answers the hard question, and the fourth is the one that shows we asked it of ourselves first.

01 · WHAT

One sentence in, a scored distribution out

The whole user journey on one line: describe an event, retrieve the historical jumps that rhyme with it, simulate 2,000 forward paths, flatten them into quantiles, score against what actually happened.

01-what.html

02 · HOW

Eight agents, one frozen interface

The module map. Every box is one file with exactly one owner lane, resting on the three frozen files nobody may edit. Pick a box and start working.

02-how.html

03 · WHY

Every guard is structure, not discipline

The 2019 boundary, the five-day embargo, the strictly-before news filter, and the null model beside every score — each with the specific failure it prevents. This is our answer to the toughest question in the room.

03-why.html

04 · RULIAL

Two earned, one hypothesis, one category error

The ensemble of reachable futures, the bounded observer that coarse-grains it, and where the realized path landed — with each borrowed Wolfram idea graded for how honestly it maps.
